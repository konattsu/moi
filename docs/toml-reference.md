# TOML リファレンス

module 定義と moi の設定ファイルの全キーを示す。動作の詳細は [仕様書](SPECIFICATION.md) と [実行モデル](execution.md) を参照。

## 共通規則

- 全階層で未知のキーを拒否する。操作にはその kind のキーだけを書ける。
- 文字列は非空。配列は個別の制約がなければ空にできる。任意の配列・テーブルの省略時は各キーの規則に従う。個別の指定がなければ空を意味する。
- 名前は単一のパス要素。空白、制御文字、`/`、`.` と `..` 単独を禁止する。
- 配置パスは絶対パスまたは `~` / `~/...`。HOME 展開後に区切りと `.` を正規化する。標準操作の配置先の親に symlink を許可しない。
- 相対パスは `/` から始めず、`..` 要素を含めない。`.` は基準ディレクトリ自身を表す。
- パスには制御文字、`$`、バッククォートを含めず、配置パスにも `..` 要素を許可しない。shell 文字列内のパスは shell の規則に従う。
- `mode` は3〜4桁の8進数文字列（例: `"755"`）。省略時は権限の一致を要求せず、既存の権限を保つ。新規作成時は操作の通常の作成・コピー規則に従う。

指定 environment の全 module を構文・型・書式・依存関係まで検証する。参照ファイルの存在・配置先の状態と競合は、選択され今回の when に一致する操作について検証する。詳細は [実行モデル](execution.md#読み込み選択検証) に従う。

## module.toml

| キー | 型 | 必須 | 意味・省略時 |
| --- | --- | --- | --- |
| `name` | 名前文字列 | 必須 | module ディレクトリ名と一致させる |
| `depends_on` | 名前の配列 | 任意 | 選択に追加し、先に実行する module。重複不可。既定 `[]` |
| `note` | 文字列の配列 | 任意 | `--show-note` 指定時だけ表示する案内。実行・初回判定・表示履歴は持たない。既定 `[]` |
| `packages` | テーブル | 任意 | distro 別のパッケージ宣言。既定 `{}` |
| `env` | テーブル | 任意 | 実行環境の宣言。既定 `{}` |
| `operations` | テーブルの配列 | 任意 | `[[operations]]` で記述順に実行。既定 `[]` |

### packages

| キー | 型 | 必須 | 意味・省略時 |
| --- | --- | --- | --- |
| `packages.apt` | 文字列の配列 | 任意 | Debian 系で要求するパッケージ名。既定 `[]` |
| `packages.pacman` | 文字列の配列 | 任意 | Arch 系で要求するパッケージ名。既定 `[]` |

1要素につき1パッケージ。shell 式や package manager のオプションとして解釈しない。選択 module の宣言を集約して重複を除き、module 操作より先に導入する。追加リポジトリなどの準備が必要なものは、準備から導入まで shell に書く。

### env

| キー | 型 | 必須 | 意味・省略時 |
| --- | --- | --- | --- |
| `env.path_prepend` | 配置パスの配列 | 任意 | module 開始時に PATH の先頭へ追加し、自 module と後続へ渡す。既定 `[]` |
| `env.path_export` | 文字列 | 任意 | 全操作の成功後に PATH 全体を取得する bash script。省略時は取得しない |

path_prepend は存在しないディレクトリも許可する。path_export は宣言されていれば apply ごとに一度実行する。操作が空・全て充足・全て対象外の場合も同じ。plan では実行しない。

取得用 script の stdout は `printf '%s\0' "$PATH"` の形式とし、ログは stderr へ出す。非空の UTF-8 文字列と末尾の NUL 一つを要求し、各 PATH 要素は空でない絶対パス、制御文字不可。同じパスは最初の出現だけを残し、存在は要求しない。成功終了と出力検証の後に PATH 全体を置き換える。

導入・更新は operations に書く。取得結果は後続全体へ渡し、自 module の操作へ遡って適用しない。PATH 以外の環境変数や関数は取り込まない。起動時の環境、実行順、失敗時の契約、nvm の例は [実行モデル](execution.md#path-の取得と引き継ぎ) に従う。

### operations 共通

| キー | 型 | 必須 | 意味・省略時 |
| --- | --- | --- | --- |
| `kind` | 列挙文字列 | 必須 | `directory` / `file` / `symlink` / `block` / `archive` / `shell` |
| `when` | テーブル | 任意 | 適用する環境の条件。省略・`{}` は制約なし |

`id` や `label` は持たない。操作の配列位置は診断用で、他の操作からの参照や永続的な識別には使わない。archive の管理記録は全体配置の専用ディレクトリ、または選択配置の各ファイルの正規化した絶対パスを基準にする。

### when

全 kind で使える。各軸は AND、同じ配列の要素は OR。省略した軸に制約はない。

| キー | 型 | 必須 | 値 |
| --- | --- | --- | --- |
| `when.distro` | 列挙文字列の配列 | 任意 | `debian` / `arch`。空・重複不可 |
| `when.arch` | 列挙文字列の配列 | 任意 | `x86_64` / `aarch64`。空・重複不可 |
| `when.wsl` | 真偽値 | 任意 | `true`: WSL のみ、`false`: WSL 以外のみ |

### kind = "directory"

ディレクトリの存在と指定した権限を管理する。

| キー | 型 | 必須 | 意味・省略時 |
| --- | --- | --- | --- |
| `path` | 配置パス | 必須 | 作成・管理するディレクトリ |
| `mode` | 権限文字列 | 任意 | 対象自身の権限。自動作成する祖先には適用しない |

### kind = "file"

module 内の通常ファイルをコピーし、配置先全体の内容を管理する。

file / block の src は module 基準の相対パス。共有入力への symlink は、解決後の実体が取得した repository 内の静的な通常ファイルである場合に許可する。

| キー | 型 | 必須 | 意味・省略時 |
| --- | --- | --- | --- |
| `src` | 相対パス | 必須 | module 基準で参照する repository 内の静的な通常ファイル |
| `dst` | 配置パス | 必須 | 配置するファイル |
| `mode` | 権限文字列 | 任意 | 配置先の権限 |

### kind = "symlink"

リンク自身とリンク先の指定を管理する。リンク先の内容は管理しない。

| キー | 型 | 必須 | 意味 |
| --- | --- | --- | --- |
| `target` | 配置パス | 必須 | リンクが指すパス。HOME 展開後の絶対パスをリンクに記録する |
| `dst` | 配置パス | 必須 | symlink を置くパス |

リンク先の存在は要求しない。異なるリンク先は差し替えるが、通常ファイルやディレクトリは上書きしない。

### kind = "block"

UTF-8 テキストの marker 区間を管理し、区間外を保持する。

| キー | 型 | 必須 | 意味 |
| --- | --- | --- | --- |
| `src` | 相対パス | 必須 | module 基準で参照する repository 内の静的な UTF-8 テキストファイル |
| `dst` | 配置パス | 必須 | 区間を挿入・更新する UTF-8 テキストファイル |
| `marker` | 文字列 | 必須 | 区間名。制御文字、`>>>`、`<<<` を禁止する |

開始行は `# >>> <marker> >>>`、終了行は `# <<< <marker> <<<`。区間がなければ末尾に追加する。同じ配置先では marker を一意にする。

### kind = "archive"

一つの配布物から宣言した内容を取り出して配置する。全項目を同じ `[[operations]]` に直接書く。

| キー | 型 | 必須 | 意味 |
| --- | --- | --- | --- |
| `dst` | 配置パス | 必須 | 配置先の基点。include 省略時は全体を管理する専用ディレクトリ、指定時は共有可能な親ディレクトリ |
| `policy` | 列挙文字列 | 必須 | pinned: 管理範囲の配布内容に収束。preserve: 同じ定義の間は必須パスの条件を満たす内容更新を保持 |
| `version` | 文字列 | 必須 | 配布物の版の識別子。大小比較はせず、記録と異なれば再導入。latest は不可 |
| `url` | 文字列 | 必須 | 配布物の HTTPS URL |
| `sha256` | 文字列 | 必須 | 配布物の SHA-256。16進数64文字、大小文字不問 |
| `format` | 列挙文字列 | 必須 | tar.gz / tar.xz / zip |
| `root` | 相対パス | 必須 | archive 内の基点ディレクトリ。`.` は展開ルート |
| `include` | 相対パスの配列 | 任意 | root 内の通常ファイルを完全一致で選ぶ。非空・重複不可。省略時は root 全体を配置 |
| `required_paths` | 相対パスの配列 | preserve で必須 | dst 内で存在・種類・必要な実行権限を確認するパス。非空・重複不可。pinned には指定不可 |

include は元の相対位置を保って配置する。ディレクトリ・symlink・root 自身は指定できず、glob・除外・リネーム・内容加工は行わない。選択したファイルだけを所有し、dst 内の他のファイルや親ディレクトリの権限は管理しない。選択配置の required_paths は、正規化後に include の部分集合とする。

条件は他の操作と同じ when に書く。architecture 共通なら when.arch を省略し、異なる配布物だけ排他的な別操作に分ける。

version・sha256・format・root・include の集合・policy の変更は両 policy とも再導入の理由とする。URL のみの変更や include の順序は理由にしない。include から外したファイルと記録は自動削除しない。定義変更・修復時の downgrade は防止しない。[archive の配置と管理](archive.md) に従う。

### kind = "shell"

標準操作で表せない独自処理を実行する。生成ファイルの作成・配置や追加リポジトリからの導入はここに書く。必要な sudo も script に明記する。

| キー | 型 | 必須 | 意味・省略時 |
| --- | --- | --- | --- |
| `run` | 文字列 | 必須 | module ディレクトリで実行する bash script。errexit / pipefail を有効にする |
| `check` | 文字列 | 任意 | 副作用のない状態判定。`0`: 充足、`1`: 未充足、その他: 判定エラー。省略時は apply ごとに run を実行 |

check 付きでは未充足時だけ run を実行し、その成功後に check を再評価する。各 script は独立した非対話・非ログインの bash で実行し、`BASH_ENV` や起動元の Bash 関数は引き継がない。check / run は plan では起動しない。

## config.toml

`~/.config/moi/config.toml` に置く。全キーは任意の文字列で、未知のキーは拒否する。ファイル自体も省略できる。優先順位は CLI、環境変数、config、既定値の順。

| キー | 必須 | 意味・制約 | 既定値 |
| --- | --- | --- | --- |
| `default_environment` | 任意 | 選択する environment の名前 | なし。plan / apply では最終的な解決値が必須 |
| `default_folder_name` | 任意 | repository 基準の相対パス | `environments` |
| `default_source` | 任意 | HTTPS Git URL または `file:///` の絶対パス | `https://github.com/konattsu/moi.git` |
| `default_install_source` | 任意 | install script の基準位置。HTTPS URL、`file:///`、絶対パス、HOME 展開パス、cwd 基準の相対パス | `https://raw.githubusercontent.com/konattsu/moi/main/` |
| `default_install_script` | 任意 | install source 内の相対パス | `install.sh` |

install source / script は `install-command` で使う。`install-command` の environment は config に頼らず CLI で明示する。branch 指定の `MOI_BRANCH` は環境変数であり、config キーではない。
